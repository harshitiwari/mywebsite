  <h2>When more cores do more than share the work</h2>
  <p>Simulating turbulent flows in stars and Earth's atmosphere requires resolving structures across a vast range of scales. DHARA is a Python framework for these demanding calculations, combining a readable scientific interface with computational kernels and parallel execution on CPUs and GPUs.</p>
  <p>On KAUST's Shaheen III, DHARA scales to <strong>786,432 CPU cores</strong> for compressible convection. Its strong scaling can be super-linear: increasing the core count reduces the time per step by more than the increase in computing resources alone would suggest. Profiling traces this effect to the memory hierarchy. Smaller subdomains fit into fast processor caches, reducing cache misses and improving per-core throughput.</p>
  <p>The work also examines GPU scaling on Frontier at OLCF and Polaris at ALCF, showing how the same framework supports extreme-scale simulations across different computing architectures.</p>
